## Featured project

### [Keepsmile](https://github.com/jake-378/keepsmile)

A Python project for controlling compatible Keepsmile Bluetooth LED lights from Windows, with a library, command-line interface, and desktop GUI. It uses Bleak for Bluetooth Low Energy communication and includes protocol research for interoperability.

The modern protocol has been tested with a KS03~ light on Windows 11. Support for older devices is implemented but still needs testing on hardware.
